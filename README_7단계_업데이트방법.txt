출퇴근 인증 알림 앱 7단계 수정본
- 하단 홈/인증기록/설정/관리 메뉴 클릭 문제 수정
- 이벤트 위임(event delegation) 적용
- GPS 출퇴근 인증 유지
- 직원명/직원번호 및 인증기록 유지
- CSV 다운로드 유지
- 서비스워커 캐시 v7 적용

GitHub Pages 업데이트:
1. 압축을 풀어 모든 파일을 기존 저장소에 덮어쓰기
2. GitHub에서 Commit changes
3. 1~3분 정도 기다림
4. 스마트폰의 설치된 앱을 완전히 종료 후 다시 실행
5. 메뉴가 계속 예전이면 Chrome에서 실제 주소를 직접 열어 새 버전 확인 후 앱 재실행

주의:
현재 기록은 각 휴대폰의 LocalStorage에 저장됩니다. 중앙 관리자 기능은 아직 서버 연결 전 단계입니다.
예약 알림은 앱이 완전히 종료된 경우 안정적으로 보장되지 않습니다. 향후 Web Push/FCM 등의 서버 기반 알림이 필요합니다.

출퇴근 누락방지 알림앱 — 15단계 안정화본

이번 버전은 기존 설치형 PWA가 오래된 HTML/JS를 계속 보여주는 문제를 줄이기 위해 Service Worker를 최신 파일 우선(network-first) 방식으로 변경했습니다. 앱 화면에 v15 표시가 나타나면 최신본입니다.

# 출퇴근 누락방지 알림앱 — 11단계

기존 출퇴근 시스템을 대체하지 않고 개인이 인증 누락을 방지하기 위해 사용하는 보조 앱입니다.

### 이번 버전 변경
- 출근 알림 시간 자유 설정
- 퇴근 알림 시간 자유 설정
- **알림 받을 요일을 사용자가 직접 선택**
- 기본값은 월~금
- 토요일/일요일도 필요하면 선택 가능
- 근무지명 + 근무지 주소 + 위도/경도 + 인증반경 관리
- 중앙 서버/관리자 모드 없음
- 기록은 휴대폰 내부에만 저장
- GPS는 인증할 때만 사용

※ 이전 버전은 토요일과 일요일에는 알림 코드를 실행하지 않도록 되어 있었습니다. 따라서 오늘처럼 토요일에는 설정 시간이 맞아도 알림이 오지 않는 것이 정상적인 동작이었습니다.
※ PWA의 JavaScript 타이머 방식은 앱이 완전히 종료된 상태에서 정확한 알림을 보장하지 않을 수 있습니다.


## 13단계 안정화본
- 하단 홈/인증기록/설정 버튼을 명시적으로 연결하여 설정 화면 이동 문제를 수정했습니다.
- 회사 로고를 상단에서 크게 표시하도록 개선했습니다.
- 알림 테스트는 서비스워커 알림을 우선 사용하도록 개선했습니다.
- 월~일 7일을 선택할 수 있으며 평일/매일/전체 해제 빠른 선택을 제공합니다.
- 이 앱은 기존 출퇴근 시스템을 대신하지 않는 개인용 보조 앱입니다.
- 중요한 제한: 웹/PWA의 자바스크립트 타이머 방식은 앱이 완전히 종료되거나 브라우저가 백그라운드에서 중지한 상태에서 예약 알림을 보장하지 않습니다. 완전한 백그라운드 예약 알림은 추후 Android 네이티브 방식으로 전환해야 합니다.

# 출퇴근 누락방지 알림앱 — 10단계

기존 출퇴근 시스템을 대체하지 않고, 개인이 인증 누락을 방지하기 위해 사용하는 보조 앱입니다.

### 이번 버전
- 출근/퇴근 알림 시간을 사용자가 직접 변경
- 근무지명 + 근무지 주소를 함께 표시
- GPS 등록 시 위도/경도 저장
- 설정 화면에서 주소와 좌표를 함께 확인
- 중앙 서버/관리자 모드 없음
- 인증 기록은 휴대폰 내부에만 저장
- GPS는 인증할 때만 사용
- 주소 자동조회 API를 사용하지 않아 외부 주소 서비스로 위치정보를 전송하지 않음

※ PWA의 JavaScript 방식 알림은 앱이 완전히 종료된 상태에서 정확한 알림을 보장하지 않을 수 있습니다. 향후 알림의 확실성을 최우선으로 한다면 서버 없이 휴대폰 자체 알람을 사용하는 Android 앱 방식이 적합합니다.

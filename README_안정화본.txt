출퇴근 인증 알림 - 안정화본

7단계에서 실제 작동했던 구조를 기준으로 개인용 보조 PWA로 정리했습니다.
- 관리자/중앙관리 기능 제거
- 홈/인증/기록/설정 4개 메뉴
- 출퇴근 시간 자유 설정
- 월~일 알림 요일 선택
- GPS는 인증 시에만 사용
- 즉시 알림 테스트는 Service Worker 우선 사용
- 캐시는 network-first 방식으로 변경

중요: 표준 PWA의 setInterval 예약은 앱/브라우저가 완전히 종료되면 실행이 보장되지 않습니다. 이 버전은 앱이 열려 있거나 백그라운드 실행이 유지되는 경우의 최선의 방식이며, 정확한 종료 상태 예약 알림은 별도 OS 기능 또는 푸시 서버가 필요합니다.

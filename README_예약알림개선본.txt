출퇴근 인증 알림 앱 - 예약 알림 개선본

변경점
1. 기존 화면/홈·인증·기록·설정 메뉴는 유지합니다.
2. 예약 알림이 예약 시각보다 조금 늦게 실행되어도 최대 2분까지 놓치지 않도록 수정했습니다.
3. 예약 알림도 Service Worker showNotification()을 우선 사용하도록 수정했습니다.
4. Service Worker 캐시 버전을 commute-stable-2로 올렸습니다.

중요
- 이 버전은 기존 PWA 방식을 그대로 유지합니다.
- 표준 PWA는 앱/브라우저가 완전히 종료되거나 Android가 백그라운드 실행을 중단하면 정확한 시각의 로컬 알람을 보장할 수 없습니다.
- 따라서 먼저 '앱을 설치한 상태에서 화면을 끈 상태'로 1~2분 뒤 예약 알림을 테스트합니다.
- 이 테스트가 실패하면 PWA 자체의 백그라운드 실행 제약인지 확인하는 단계로 넘어갑니다.

출퇴근 인증 알림 앱 6단계
- 5단계 기능 유지
- 직원 이름/번호 저장
- 날짜별 출퇴근 인증 기록 누적
- 최근 20일 기록 조회
- CSV 다운로드
- 전체 기록 삭제
- 하단 메뉴 홈/인증기록/설정/관리 이동
- 관리자 기능의 UI 기반 마련

주의: 현재 데이터는 각 스마트폰의 브라우저 저장소(LocalStorage)에 저장됩니다.
여러 직원의 기록을 중앙에서 모으려면 다음 단계에서 Firebase 또는 Supabase 같은 서버 저장소를 연결해야 합니다.

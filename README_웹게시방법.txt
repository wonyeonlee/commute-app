출퇴근 인증 알림 앱 - 5단계

이번 버전:
1. 출근/퇴근 알림 시간을 설정할 수 있습니다.
2. 알림 권한 확인 및 테스트 기능이 있습니다.
3. 다음 알림 시간을 화면에 표시합니다.
4. 앱이 열려 있거나 백그라운드에서 유지되는 동안 예약 알림을 시도합니다.
5. 한국시간 기준 날짜를 사용하도록 날짜 계산을 개선했습니다.
6. 서비스워커 캐시 버전을 v5로 올려 업데이트 충돌을 줄였습니다.

중요:
브라우저/PWA만으로는 Android에서 앱이 완전히 종료된 상태에서도 특정 시각에 항상 알림을 보장하기 어렵습니다.
완전한 자동 알림을 원하면 다음 단계에서 Web Push + 서버(예: Firebase Cloud Messaging)를 연결해야 합니다.

# 출퇴근 인증 알림앱 - 웹 게시용

이 폴더의 파일을 정적 웹호스팅(GitHub Pages, Netlify 등)에 올리면
스마트폰 Chrome에서 HTTPS 주소로 접속하여 PWA 형태로 사용할 수 있습니다.

## 포함 파일
- index.html : 앱 화면
- style.css : 모바일 디자인
- app.js : 출퇴근/GPS 인증 로직
- manifest.json : PWA 설치 정보
- service-worker.js : 오프라인 캐시
- logo.png : 기관 로고
- icon-192.png / icon-512.png : 앱 아이콘

## 중요
현재 버전은 GPS 인증을 지원합니다.
근무지에서 앱을 열고 [현재 위치를 근무지로 등록]을 한 뒤,
출퇴근 인증 시 설정된 반경(기본 100m) 안에서만 인증됩니다.

주소는 설정 화면에서 언제든지 변경할 수 있습니다.

## GitHub Pages 게시 순서
1. GitHub에서 새 저장소(repository)를 만듭니다.
2. 이 폴더의 파일 7개를 저장소의 최상위에 업로드합니다.
3. 저장소 Settings -> Pages에서 배포 방식을 활성화합니다.
4. 생성된 HTTPS 주소를 스마트폰 Chrome에서 엽니다.
5. Chrome 메뉴에서 '홈 화면에 추가' 또는 '앱 설치'를 선택합니다.
